# SPEC-004: Keep-awake

**Crate**: `crates/sciart-keepawake` · **Milestones**: M3, M25 (Linux inhibitor) · **Status**: Implemented (KA-R1..R6 in M3; KA-R7..R9 in M25)

- **KA-R1** `Mode = Caffeinate | Mouse | Off`; parsed from `caffeinate|mouse|off`. Default: `Caffeinate` on macOS, `Off` elsewhere.
- **KA-R2** `start(mode, seed) -> Result<Guard, KeepAwakeError>`; the guard releases the assertion on `Drop`. Errors are reported, never fatal: the binary prints a warning and continues with `Guard::failed(mode)` (status `<mode>:unavailable`). `Guard::off()` is the explicit no-op guard.
- **KA-R3** `ChildGuard` (unix) owns a helper process: killed and reaped on `Drop`; `poll()` notices if it exited on its own. `Caffeinate` (macOS only, `cfg(target_os = "macos")`) is a `ChildGuard` running `caffeinate -dimsu -w <own pid>` — the `-w` makes it exit by itself if sciart dies without cleanup.
- **KA-R4** `Jiggler<M: Mover>` (always compiled, pure logic): after every `interval` (15 s) of `poll(elapsed)` time it asks the `Mover` for the screen size and moves to a seeded-random point with a 50 px margin (margin shrinks to `size/4` on screens smaller than 200 px). Any `Mover` error is swallowed and counted (Python R2.1 equivalent). The real `Mover` (enigo) exists only with cargo feature `mouse`; without it `start(Mouse)` returns `Unsupported`.
- **KA-R5** `Guard::status()` is a short HUD string: `caffeinate:on`, `caffeinate:exited`, `mouse:on`, `mouse:err(<n>)`, `<mode>:unavailable`, `off`.
- **KA-R6** Backends implement `trait Backend { fn status(&self) -> String; fn poll(&mut self, elapsed: f64) }`; `Guard::new(Box<dyn Backend>)` lets tests inject fakes.
- **KA-R7** (M25, ADR-0028) `Mode::Inhibit` (parsed from `inhibit`): on Linux, a `ChildGuard` running the first helper found on `PATH` of `systemd-inhibit`, `elogind-inhibit`, as `<helper> --what=idle:sleep --mode=block --who=sciart --why="sciart is running" cat`. The guard keeps the write end of the helper's stdin: `cat` reads end-of-file and the helper releases its lock when sciart exits for any reason, `SIGKILL` included (the role `caffeinate -w` plays on macOS). On `Drop` the guard closes that pipe before it kills and reaps the helper. Status strings follow KA-R5: `inhibit:on`, `inhibit:exited`, `inhibit:unavailable`. With no helper on `PATH`, or on another OS, selecting `inhibit` is reported under KA-R2: a warning, never fatal. The helper choice and its argument list are a pure function compiled on every platform, and the piped guard is `cfg(unix)`, so both are tested on macOS with a stand-in helper.
- **KA-R8** (M25, ADR-0028) The default mode is a pure function of the OS and the environment, `Mode::default_for(os, env)`: `Caffeinate` on macOS; on Linux `Inhibit` for a local session and `Off` for a remote one (`SSH_CONNECTION` or `SSH_TTY` set, whatever `DISPLAY` says, since X forwarding sets it too: keeping a remote host awake is not what someone watching over SSH wants); `Off` elsewhere. `platform_default()` calls it with the real environment. An explicit `--keep-awake` or config value always wins. Amends KA-R1's default.
- **KA-R9** (M25) A piped helper leaves nothing running: after its guard drops, and after the process holding the guard is killed with `SIGKILL`, no helper it started remains. The tests use a stand-in helper, so the suite passes on hosts without logind (containers, CI, macOS).
