# Keys

While the art runs:

| Key | Action |
| --- | --- |
| `n` or `→` | next scene |
| `p` or `←` | previous scene |
| `space` | pause or resume |
| `r` | restart the current scene |
| `h` | show or hide the status line |
| `t` | next theme: astro, rainbow, mono, aurora, colorblind |
| `?` | help overlay (`Esc` closes it) |
| `f` | mark or unmark the current scene as a favourite |
| `v` | show only favourites |
| `[` and `]` | previous and next category |
| `s` | shuffle the order of the cycle |
| `q`, `Esc` or `Ctrl-C` | quit |

Favourites marked with `f` last for the session; to keep them, list them under
`favorites` in the [configuration](configuration.md) file.

The [player](../play/index.html) on this site uses the same letters where they make
sense: `space` to pause, `n` and `p` for the next and previous scene, `t` for the next
theme and `r` to restart.
